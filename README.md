# Alliance Hub

So what I wanna do is I wanna create something that functions as an app to help myself and other leaders in a game that I play manage our alliance. Some things to understand about this game is that there are many events and many metrics that we need to track and use for different reasons. And at any given time, we have 100 members in our alliances and their stats and things change. And we need a way to be able to track things like attendance to events, set people up within certain teams on events, track their metrics that we'll be able to update regularly, use some of those metrics on a point system to determine their ranking at any given time, basically a holistic way to track power, progress, and participation.
